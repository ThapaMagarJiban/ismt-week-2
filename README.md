# Community Event Management System

## Overview
This is an ASP.NET Core MVC application developed to manage community events, participants, venues, and activities.
It demonstrates Object-Oriented principles, including Inheritance, Interfaces, Polymorphism, and Encapsulation. It also incorporates Design Patterns like the Repository Pattern and Dependency Injection.

## Prerequisites
- .NET 10 SDK

## Running the Application
1. Navigate to the source code folder: `cd src/CommunityEventManagement`
2. Build the project: `dotnet build`
3. Run the project: `dotnet run`
4. Access the web application via `http://localhost:5000` (or the port specified in your console).

## Running Tests
1. Navigate to the tests folder: `cd src/CommunityEventManagement.Tests`
2. Run the tests: `dotnet test`
